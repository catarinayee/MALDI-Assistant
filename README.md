# MALDI-Assistant
Assists with MALDI workflow

This is a notebook made to streamline a lab member's workflow that involves a lot of file editing and cleanup. It performs the following:

1) Merges two METASPACE datasets together / allows you to upload one
2) Cleans the file of the METASPACE dataset[s] and filters for raw Off percentage and duplicates
3) Exports the list of m/z values to input into your project in SCiLS so that you can get the concentration values at those m/z values
4) Takes the export from SCiLS to clean it and add the molecule name, addutct, ion, and database number via the m.z
5) Exports that file so you can hand it off for data analysis

This saves a little bit of time and effort and is a little more consistent!
